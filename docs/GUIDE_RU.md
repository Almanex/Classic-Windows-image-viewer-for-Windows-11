# Руководство пользователя Classic Windows Photo Viewer — Как вернуть старый просмотрщик в Windows 11

> [!NOTE]
> Classic Windows Photo Viewer — это легковесная утилита с открытым исходным кодом, возвращающая классический быстрый интерфейс «Средства просмотра фотографий Windows» в современных системах Windows 10 и 11. Данная инструкция содержит пошаговое руководство по скачиванию, установке и настройке ассоциаций файлов.

С помощью утилиты **Shell Image Viewer** вы можете легко заменить стандартное медленное приложение «Фотографии» и вернуть привычный скоростной просмотрщик без сложного редактирования системного реестра.

## Быстрый старт

1. **Шаг 1: Скачивание приложения** — Перейдите в раздел релизов на GitHub и скачайте исполняемый файл `PhotoViewer.exe` из последней версии:
   * [Релизы Shell Image Viewer на GitHub](https://github.com/Almanex/Classic-Windows-image-viewer-for-Windows-11/releases)
2. **Шаг 2: Размещение исполняемого файла** — Переместите скачанный исполняемый файл `PhotoViewer.exe` в любую постоянную папку на вашем компьютере (например, в корневой раздел диска `C:\` или в папку `C:\Program Files\PhotoViewer\`).
   > [!WARNING]
   > **Windows Defender SmartScreen и первый запуск:**
   > При первом запуске или сопоставлении файлов защитник Windows может выдать предупреждение: **«Система Windows защитила ваш компьютер»**.
   > Это стандартная реакция Microsoft Defender на новые независимые утилиты (open-source) без платной цифровой подписи.
   > Чтобы запустить программу:
   > 1. Нажмите на ссылку **«Подробнее»** (More info).
   > 2. Нажмите на появившуюся кнопку **«Выполнить в любом случае»** (Run anyway).
3. **Шаг 3: Выбор приложения для открытия изображений** — Щёлкните правой кнопкой мыши по любому файлу изображения (например, `.jpg` или `.png`) и выберите пункт меню **«Открыть с помощью»** (Open with) → **«Выбрать другое приложение»** (Choose another app).
4. **Шаг 4: Указание пути к PhotoViewer.exe** — Прокрутите список доступных программ в самый низ, нажмите ссылку **«Еще приложения»** (More apps), затем выберите пункт **«Найти другое приложение на этом компьютере»** (Look for another app on this PC). В открывшемся окне Проводника перейдите к папке, в которую вы сохранили файл `PhotoViewer.exe` (из Шага 2), выберите его и нажмите кнопку **«Открыть»** (Open).
5. **Шаг 5: Ассоциация типов файлов** — Выберите способ использования приложения. Чтобы всегда использовать эту программу для данного типа файла, нажмите кнопку **«Всегда»** (Always). Чтобы использовать один раз, нажмите кнопку **«Только один раз»** (Just once).
   > [!TIP]
   > **Настройка для всех форматов:**
   > Повторите процедуру сопоставления (Шаги 3–5) для основных форматов изображений, которые вы используете: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.gif`, `.tiff`.
